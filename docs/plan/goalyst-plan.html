Sheet 01 / 16

The problem

Every serious student is running their prep off five broken tools

The notes live in a Telegram channel. The habit tracker doesn't know what a NEET syllabus is — it just wants a streak. Doubts go to YouTube comments or get shelved for the next coaching class. The study plan lives in a diary nobody re-opens after day four. And real AI tutoring sits behind a subscription most families won't justify for one subject, let alone six.

None of these tools were built for a student chasing one specific, dated goal.

Nobody owns the whole loop: plan the goal, make the student practice like it's the real exam, and show up when motivation runs out on its own.

Sheet 03 / 16

Who it's for

Four kinds of student, one loop underneath

Profile A

The NEET / JEE aspirant

Six subjects, one shot a year, a syllabus too big to hold in one head. Needs a milestone plan that doesn't collapse the first time they fall behind, and mocks with real negative marking.

Profile B

The state-exam aspirant

SSC, state police, prep material scattered across ten Telegram channels, a pattern that changes by state. Needs a tool that adapts to their exact exam — a state-wise library of eligibility, pattern, and previous papers, not a NEET-shaped tool wearing a different label.

Profile C

The skill-builder

Learning to code, design, or communicate — no external exam date forcing urgency, so momentum usually dies in week two. Needs milestones that manufacture their own deadlines.

Profile D

The habit-builder

Not studying for anything specific, just trying to become someone who follows through. Needs a streak that feels earned, not gamified for its own sake.

Where Goalyst sits

The market already has players — none of them own the whole loop

Every one of these does one piece of what a serious student needs. None of them do all three at once: plan the goal, practice like it's real, and coach the gap in between.

PlayerStrong atMissing for this student
Testbook, Adda247 Deep mock-test and question-bank libraries across exams. No dated milestone plan, no coach to ask when a student falls behind — a mock is just a mock.
Unacademy, PhysicsWallah Video lectures and live classes at real production quality. Priced for a full course, not a free daily loop — and it's still one-way, not a coach that answers back.
Habitica, Streaks Genuinely good streak and habit mechanics. Has never heard of a NEET syllabus — a streak with no exam behind it doesn't survive a bad week.
ChatGPT / Gemini, ad hoc Free, flexible, answers almost anything. Forgets the goal every new chat, no milestone plan, no marking-scheme mocks — a tool the student has to drive, not one built around them.

The edge isn't a better mock engine or a smarter chatbot on its own — it's the one app that plans the goal, runs the practice, and coaches the gap, without asking a family to stitch four subscriptions together.

What it's built on

The tech stack, and why each piece earns its place

Every layer below has a real free tier — Term 1 was built on all of them without a hosting bill. The stack doesn't change for Term 2, it just gets used harder.

LayerToolWhy this one
Frontend React (Next.js) One codebase for the web app today, with a component layer that carries over cleanly if it's wrapped into a native app later.
Backend & API Next.js API routes Serverless by default — no separate backend to run or pay for at this scale, and it deploys with the same command as the frontend.
Database & auth Supabase (Postgres) A free tier that comfortably covers Term 1–2, relational tables that fit goals → milestones → mocks naturally, and row-level security to keep one student's data walled off from another's.
AI coach
Term 3		 Claude API, server-side Matches the Term 3 upgrade already on the roadmap — kept server-side so the API key and prompt logic never ship to the client.
Hosting & deploys Vercel Zero-config deploys straight from git, free through Term 2, and the same platform this plan's cost estimates are already built around.
Payments
Term 4		 Razorpay Built for ₹ subscriptions and UPI — the standard choice for an India-first product, where Stripe's coverage falls short.
Native wrap
Term 4		 Capacitor Wraps the existing web app for the Play Store and App Store without a separate native rewrite.

Term 3 is the first time a real bill shows up — and it's only for AI coach usage, not for anything else in this table.

Sheet 15 / 16

The name

Goalyst, and two backups

Goalyst

Goal + the “-yst” of catalyst/analyst — reads as “the thing that makes goals happen.” Short, easy to say and type, works as a domain and a handle.

Recommended
GoalKarma

Same core idea, more Indian-English flavor — the effort you put in catching up with you. Slightly longer, still clean.

Runner-up
GoalNudge

Plainer and very literal — leans into the daily-nudge mechanic rather than the brand feel. Safe fallback.

Alternate
Rechecked as requested: Studently, which was on the first list, turned out to be already taken — a live app of that exact name is on Google Play. It's been dropped and replaced with GoalNudge above, which came back clear.

Worth avoiding

Sankalp, Manzil, Siddhi, Lakshya, ExamSaathi, Prepzy, GoalCraft, AimForge, Aimwell, and Pathlyst are all already in use by real apps or projects — checked directly before this list was written.

This is a quick name-collision search, not a trademark or domain-availability check. Confirm both before locking one in.
